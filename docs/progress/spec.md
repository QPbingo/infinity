# 进展与验收 — 执行标准

> 本文件定义「任务进展跟踪」与「验收记录」的规范、模板与约束。
> 实际进展记录写入 `./progress.md`，本文件不承载实际数据。

---

## 1. 使用规则

| 规则 | 说明 |
|------|------|
| 更新时机 | 每个子任务状态变更时立即更新 `./progress.md` |
| 状态枚举 | `pending`（未开始）/ `in_progress`（进行中）/ `completed`（已完成）/ `blocked`（阻塞） |
| 验收记录 | 子任务标记 `completed` 前，必须在 progress.md 填写验收记录 |
| 验收方法 | 对照 `../task/task.json` 中该子任务的 `acceptance_criteria` 逐条检验 |
| 闭环要求 | 所有子任务 `completed` 后，顶层任务方可标记 `completed` |

## 2. 进展记录模板

```markdown
## [task_id] 任务标题

| 字段 | 值 |
|------|----|
| task_id | T001 |
| 用户需求 | （摘录用户原始需求） |
| 创建时间 | 2026-06-18T10:00:00 |
| 顶层状态 | in_progress |

### 子任务进展

| 子任务 ID | 标题 | 状态 | 开始时间 | 完成时间 | 备注 |
|-----------|------|------|---------|---------|------|
| T001-1 | 创建说明文档 | completed | 10:05 | 10:45 | 4 份文档已创建 |
| T001-2 | 创建任务文档 | in_progress | 10:45 | — | 进行中 |
| T001-3 | 编辑 agent_claude.md | pending | — | — | 依赖 T001-1, T001-2 |
```

---

## 3. 验收记录模板

每个子任务完成时，在 `./progress.md` 填写验收记录：

```markdown
### 验收记录：T001-1 创建说明文档

**验收时间：** 2026-06-18T10:45:00

| 验收项（acceptance_criteria） | 验收方法 | 验收结果 | 备注 |
|------------------------------|---------|---------|------|
| 条件1 | 检查方法 | ✅ 通过 | 备注 |
| 条件2 | 检查方法 | ✅ 通过 | 备注 |

**验收结论：** ✅ 通过（N/N 验收项全部通过）
```

---

## 4. 阻塞记录模板

子任务遇到阻塞时，在 `./progress.md` 填写：

```markdown
### 阻塞记录：T001-3 编辑 agent_claude.md

**阻塞时间：** 2026-06-18T11:10:00
**阻塞原因：** （描述阻塞原因）
**影响子任务：** T001-3
**处理方案：** （描述处理方案）
**解除时间：** 2026-06-18T11:15:00（解除时填写）
```

## 5. 最终交付总结模板

所有子任务完成后，在 `./progress.md` 填写交付总结：

```markdown
## 最终交付总结

| 字段 | 值 |
|------|----|
| task_id | T001 |
| 任务标题 | （标题） |
| 完成时间 | 2026-06-18T11:30:00 |
| 最终状态 | completed |

### 交付物清单

| 文件 | 类型 | 说明 |
|------|------|------|
| xxx | 新建/编辑 | 说明 |

### 验收总览

| 子任务 | 验收项数 | 通过数 | 结论 |
|--------|---------|--------|------|
| T001-1 | 5 | 5 | ✅ 通过 |
| **合计** | **N** | **N** | **✅ 全部通过** |

### 遗留问题

（无 / 或列出未解决的事项及后续建议）
```

## 6. 输出文件结构

`./progress.md`（实际进展记录）按以下结构组织：

```markdown
# 任务进展 — 执行记录

> 规范定义见 ./spec.md

## 当前任务
（进展记录表）

## 验收记录
（逐条验收记录）

## 阻塞记录
（阻塞与解除记录）

## 最终交付总结
（交付总结）
```

## 7. 与其他文档的关系

| 关联文档 | 关系 |
|---------|------|
| `../task/spec.md` + `../task/task.json` | task.json 定义任务与验收标准，progress.md 检验并记录结果 |
| `../log/spec.md` + `../log/loginfo.md` | 日志的 verifying/done 结论驱动 progress.md 中的状态更新 |
| `../../agent_claude.md` 「任务信息」段落 | 定义执行约束：执行过程中必须更新 progress.md |
