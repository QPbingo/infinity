# 设计风格说明

> 本文件定义 Web 看板的视觉设计规范，提取自 `web/dashboard.html` 内联 CSS。
> 前后分离后，本规范作为 `web/frontend/src/styles/main.css` 的设计基线。

---

## 1. 主题

**GitHub Dark 风格** — 深色背景、低饱和度文字、蓝色主色调，强调可读性与信息密度。

---

```css

```


## 7. 组件样式规范

### 卡片（Session Card）

- 背景 `#161b22`，边框 `#21262d` 1px，圆角 `8px`
- header：`display:flex`，高 `36px`，hover 背景 `#1c2128`
- body：默认隐藏，`.open` 时 `display:block`，背景 `#0d1117`，上边框分隔

### 时间线（Timeline）

- Turn 容器：边框 `#21262d` 1px，圆角 `6px`
- Turn header：背景 `#1c2128`，`font-size: 0.75em`，`#8b949e` 文字
- 最新 Turn 默认展开，其余折叠
- 用户输入文本块：背景 `#1a2332`，圆角 `4px`，`padding: 8px 12px`

### 工具组（Tool Group）

- 工具卡片：背景 `#010409`，边框 `#21262d`，圆角 `4px`
- 工具名：`#d2a8ff`，`font-weight: 600`，等宽字体
- input/output：`#8b949e`，等宽，`max-height: 60px` 可滚动
- 长文本：output > 200 字符或 > 3 行可折叠

### 弹窗（Modal）

- 遮罩：`rgba(0,0,0,0.6)`，`z-index: 200`
- 弹窗体：背景 `#161b22`，边框 `#30363d`，圆角 `8px`，`padding: 20px`，宽 `360px`
- 主按钮：背景 `#238636`，白色文字
- 取消按钮：背景 `#21262d`，边框 `#30363d`

### 树节点（Tree Node）

- 行高紧凑（`padding: 3px 14px`），`font-size: 0.78em`
- 箭头：`font-size: 0.55em`，展开时 `rotate(90deg)`
- 添加按钮（`+`）：默认隐藏，hover 行时显示，`#58a6ff`

### 认证遮罩（Auth Overlay）

- 全屏 `#0d1117`，`z-index: 100`
- 登录框：背景 `#161b22`，圆角 `8px`，宽 `340px`
- 错误提示：`#f85149`

## 8. 字号规范

| 场景 | 字号 |
|------|------|
| 页面标题 h1 | `1.1em` |
| 侧边栏标题 h2 | `0.9em` |
| 卡片标题 | `0.82em` |
| agent 类型标签 | `0.78em` |
| 常规正文/卡片 meta | `0.75em ~ 0.8em` |
| 树节点 | `0.78em` |
| 标签/次要文字 | `0.68em` |
| 时间戳/最弱文字 | `0.65em` |

> 整体采用 em 相对单位，基准为浏览器默认 16px，实际渲染偏小以提升信息密度。
